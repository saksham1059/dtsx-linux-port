# Public repository policy

This repository publishes the independent Linux implementation, its test
suite, derived profiles, documentation, and reproducible analysis tooling.

It does not publish proprietary DTS/HP Windows binaries, OEM configuration
blobs, or OEM licence material. Those inputs remain local evidence used during
clean-room research and are excluded by `.gitignore`. The public project does
not link, load, execute, distribute, or require them at runtime.

The intent is to recreate a useful Linux audio-processing experience for the
HP Victus 15-fa2xxx / Realtek ALC245 platform. It is not a Windows binary port,
not an official DTS product, and not a claim of bit-exact DTS:X Ultra
equivalence.
